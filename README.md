# Zepto Sales Analysis Using SQL

## Project Overview
This project analyzes Zepto sales and order data using MySQL to understand sales performance, product demand, order status, and revenue trends.

## Objectives
- Analyze order and product data using SQL.
- Calculate total revenue from delivered orders.
- Identify top-selling products.
- Analyze order status distribution.
- Generate business insights using SQL queries.

## Tools Used
- MySQL 8.0
- MySQL Workbench
- SQL

## Database Tables
- `zepto_orders` — order details, order dates, product IDs, quantities, selling prices, order status, and customer information.
- `zepto_v2` — product details, including product names.

## SQL Concepts Used
- INNER JOIN
- SUM()
- COUNT()
- COUNT(DISTINCT)
- GROUP BY
- ORDER BY
- NULLIF()
- Aggregate functions and business KPI calculations

## Business Questions
1. What is the total revenue from delivered orders?
2. Which products sell the most?
3. How many orders are delivered, pending, or cancelled?
4. What is the total quantity of products sold?
5. What is the average revenue per order?
6. How can sales data support business decisions?

## Key Performance Indicators (KPIs)
- Total revenue
- Total delivered orders
- Total units sold
- Revenue per order
- Order status distribution
- Top-selling products

## Project Files
- `01_create_tables.sql` — database and table creation queries.
- `02_data_analysis.sql` — SQL analysis queries.
- `Zepto_Sales_Analysis.pptx` — project presentation.

## Key Learnings
- Writing SQL queries to analyze business data.
- Joining multiple tables using product IDs.
- Calculating revenue and sales KPIs.
- Identifying product performance and order trends.
- Translating data into useful business insights.

## Conclusion
This project demonstrates how SQL can be used to analyze e-commerce sales data, track key business metrics, identify top-performing products, and support data-driven decisions.
